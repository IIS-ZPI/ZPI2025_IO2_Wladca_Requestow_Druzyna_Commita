# Currency Analytics System (CAS)

Currency Analytics System (CAS) is a command-line application (CLI) written in Python designed to perform statistical analysis and calculations on currency exchange rates based on data from the official National Bank of Poland (NBP) API. 

## Technology Stack
- **Language**: Python 3.10+
- **Key Libraries**: `requests`, `statistics`, `csv`
- **Testing**: `pytest`

## Running the Application
Ensure you have Python installed. 
Note: No explicit external API keys are required as the NBP API is open.

1. Navigate to the project directory:
   `cd cas_project`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the CLI tool:
   `python main.py`
